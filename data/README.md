# 데이터 수집 가이드 (시군구 단위)

> **기준 시점: 2025년 12월 31일 (2026.7.1 인천 행정구역 개편 이전 경계)**
> 모든 파일은 이 시점(연간 통계는 2025년) 기준으로 받는다. 분석 단위는 일반구를 상위 시로 합친 기초자치단체 약 229개다.

실행 순서:
1. `python -m src.population`: 행안부 파일로 아래 두 CSV를 만든다.
   - 기준 코드표 `data/processed/population_sigungu_202512.csv`
   - 1인세대 `data/processed/single_household_sigungu_202512.csv`
2. `python -m src.disability`: KOSIS 등록장애인 파일로 `data/processed/disability_sigungu_2025.csv` 를 만든다.
3. `python -m src.fetch_emergency`: 응급의료기관 OpenAPI로 `data/processed/emergency_facilities.csv` 를 만든다.
4. `python -m src.geocode`: 카카오 검색으로 시군구 기준점 `data/processed/sigungu_centers.csv` 를 만든다(캐시).
5. `python -m src.accessibility`: 접근성 지표 `data/processed/accessibility_sigungu.csv` 를 만든다.
6. `python -m src.build_table`: 위 표들을 행정기관코드로 합쳐 `data/processed/sigungu_table.csv` 를 만든다.

3·4번은 레포 루트의 `.env` 에 키가 있어야 한다(`.env` 는 .gitignore, 절대 커밋하지 않음).

```
DATA_GO_KR_SERVICE_KEY=공공데이터포털 일반 인증키 (Encoding/Decoding 어느 쪽이든 됨)
KAKAO_REST_API_KEY=카카오 디벨로퍼스 REST API 키 (카카오맵 사용 설정 필요)
```

## 데이터 한계

- **1인세대 ≠ 실제 단독 거주**: 독거노인 수는 주민등록상 65세 이상 1인세대 수다. 같은 집에 살아도 세대를 나눠 등록하면 1인세대로 잡혀서, 실제로 혼자 사는 노인 수와 다를 수 있다.
- **일반구는 상위 시로 합산**: 수원시 장안구 같은 일반구는 상위 시(수원시)로 합쳤다. 그래서 같은 시 안의 구별 차이는 보이지 않는다. 분석 단위는 기초자치단체 229개다.
- **기준 시점 2025년 12월 (인천 개편 전)**: 2026.7.1 인천 행정구역 개편(제물포구, 영종구, 검단구 신설) 이전 경계다. 개편 후 경계 기준의 결과와는 다르다.
- **기초생활수급자 제외**: 시군구 단위 전국 공개 통계가 없어 분석에서 뺐다. KOSIS(DT_11714_N001)에는 시도 단위까지만 공개돼 있다.
- **접근성은 직선거리**: 하버사인 직선거리라 실제 도로 이동 거리보다 짧다.
- **섬 지역 해상 이동 미반영**: 직선거리라 섬 지역의 배·헬기 이동(운항 시간, 기상)을 반영하지 못한다. 옹진군·울릉군·신안군 등은 실제 접근성이 수치보다 나쁘다.
- **기준점이 시군구청**: 거리는 시청·군청·구청 한 점에서 잰다. 면적이 넓은 군은 외곽 주민의 실제 거리와 차이가 크다. 예외 처리한 시군구는 `sigungu_center_overrides.csv` 를 참고한다.
- **청사 옆 병원은 과소 추정**: 시군구청 바로 옆에 병원이 있는 지역(안동, 서대문, 부평, 거창 등)은 최근접 거리가 0.1~0.2km로 나와 주민 평균 거리보다 훨씬 짧다.
- **섬 지역 예외 처리**: 옹진·신안·완도는 읍면사무소별 거리를 읍면 인구로 가중평균한다. 울릉은 섬 하나에 인구가 모여 있어 군청 기준을 그대로 쓴다.
- **기관 기준 시점 차이**: 응급의료기관은 API 수집일 기준(2026-11-04)이고 인구는 2025년 12월 기준이다.
- **국토모니터링 공식 지표 미사용**: 국토지리정보원 국토모니터링 "응급의료시설 접근성"은 다운로드 프로그램 문제로 받을 수 없어 직접 계산했다.

## 향후 개선

- **인구가중 중심점**: 시군구청 대신 읍면동(또는 격자) 인구로 가중한 중심점을 기준점으로 쓴다.
- **전국 읍면동 인구가중 기준점**: 지금 섬 3개 군에만 쓰는 방식을 전국으로 넓힌다. 공공데이터포털의 행안부 읍면동 연령별 인구 파일과 읍면동 행정복지센터 좌표로, 읍면동별 거리를 인구로 가중평균한다.
- **도로 네트워크 거리**: 직선거리 대신 도로망 기준 이동 거리·시간을 쓴다(OSRM, 카카오 길찾기 등).
- **2SFCA**: 기관 수용력(병상·인력)과 주변 수요(인구)를 함께 고려하는 2단계 유동 영역(Two-Step Floating Catchment Area) 지표로 확장한다.

## 공통 규칙

- 지역 매칭은 **(시도명, 시군구명)** 으로 한다. KOSIS는 통계청 행정구역코드를 써서 행안부 코드와 값이 다르기 때문이다. 시도명은 `경기도`, `경기` 둘 다 되고, 시군구명의 띄어쓰기는 무시한다.
- 분석 단위는 기초자치단체(약 229개)이고, 일반구(수원시 장안구 등)는 상위 시로 합친다.
- 행안부 파일의 컬럼명은 공백·괄호·특수문자를 뺀 이름으로 비교한다(예: `총 인구수` → `총인구수`).
- 시도 칸이 첫 행에만 있어도 괜찮다(아래로 채워 넣음). `소계`, `계`, `합계` 행은 자동으로 뺀다.
- 각 스크립트가 매칭 실패와 빠진 시군구를 직접 출력한다. `build_table` 은 이미 코드가 붙은 표를 합치기만 한다.

## 1. 인구: `population/202512_202512_연령별인구현황_{지역}.xlsx`

- **출처**: 행정안전부 주민등록 인구통계 (https://jumin.mois.go.kr)
- **받는 방법**:
  1. **연령별 인구현황** 메뉴로 간다.
  2. 행정구역에서 **시도를 하나씩 고르고**(하위 시군구 전체 포함) 받는다. 받으면 파일 하나에 시도 합계 행과 그 시도의 시군구 행이 들어 있다.
  3. 연령구분 단위는 **5세**, 연령 범위는 **0~4세부터 100세 이상까지 전체**로 고른다.
  4. 조회 기간은 **2025년 12월(월간)** 으로 고르고, 엑셀로 내려받는다.
  5. 같은 설정으로 행정구역 **전국**(전국과 시도 합계)도 받는다. 이 파일은 검증용이다.
- **파일명**: 받은 그대로 `202512_202512_연령별인구현황_{지역}.xlsx` 로 둔다. 지역 이름은 아래 16개 + `전국` 이다.
  - 서울, 부산, 대구, 인천, 전남광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 경북, 경남, 제주
  - `전남광주` 파일에는 광주광역시(29…)와 전라남도(46…)가 함께 들어 있고, 따로 나눌 필요는 없다.
- **파일 구조**(`src/population.py` 가 이 구조를 전제로 읽는다):
  - 0~2행은 안내문, 기준월, 계/남/여 머리글이고, 3행(0부터 셈)이 헤더다.
  - 헤더는 `행정기관코드, 행정기관, 총 인구수, 연령구간인구수, 0~4세 … 100세 이상` 이고, 계 → 남 → 여 블록으로 반복된다. **계 블록만** 쓴다.
  - 숫자는 쉼표가 들어간 문자열이다. 행정기관코드는 10자리이고, 뒤 8자리가 `00000000` 이면 시도 합계 행이라 뺀다.
- **결과**: `data/processed/population_sigungu_202512.csv`
  - 컬럼: `행정기관코드`(5자리), `시도`, `시군구`, `총인구`, `65세이상인구`, `80세이상인구`
  - 일반구는 상위 시로 합친다. 시 합계 행과 일반구 행이 함께 있으면 시 합계 행만 쓴다.
  - 검증: 시도별 시군구 합 = 전국 파일의 시도 총인구, 전국 합 = 51,117,378명. 맞지 않으면 시도와 차이를 출력한다.
- **주의**:
  - 이 파일이 **기준 코드표**다. 다른 출처는 모두 이 파일의 (시도, 시군구) 이름에 맞춘다.
  - 연령 범위를 일부만 고르면 65·80세 이상 컬럼이 없어서 경고가 나고 해당 값이 빈칸이 된다.
  - KOSIS의 "행정구역(시군구)별/5세별 주민등록인구"는 행안부 코드 컬럼이 없어서 이 자리에 쓸 수 없다.

## 1-2. 1인세대(독거노인): `single_household/202512_202512_행정동별 성연령별 주민등록 1인세대수_{지역}.xlsx`

- **출처**: 행정안전부 주민등록 인구통계 (https://jumin.mois.go.kr)
- **받는 방법**: 인구 파일과 같다.
  1. **성/연령별 주민등록 1인세대수** 메뉴로 간다.
  2. **시도를 하나씩** 고르고(하위 시군구 전체 포함) 받는다.
  3. 연령구분 단위는 **5세**, 연령 범위는 **0~4세부터 100세 이상까지 전체**로 고른다.
  4. 조회 기간은 **2025년 12월(월간)** 으로 고르고, 엑셀로 내려받는다.
  5. 같은 설정으로 행정구역 **전국**도 받는다. 이 파일은 검증용이다.
- **파일명**: 받은 그대로 두고, 지역 이름은 인구 파일과 같은 16개 + `전국` 이다.
- **파일 구조**: 인구 파일과 같다(3행 헤더, 계 → 남자 → 여자 블록, 쉼표 숫자). 헤더는 `행정기관코드, 행정기관, 총 세대수, 총연령구간세대수, 0~4세 … 100세 이상` 이다.
- **결과**: `data/processed/single_household_sigungu_202512.csv`
  - 컬럼: `행정기관코드`(5자리), `시도`, `시군구`, `1인세대수`, `65세이상1인세대수`(= 독거노인 수), `80세이상1인세대수`
  - 검증 1: 시도별 합이 전국 파일과 같은지 본다. 전국 파일이 없으면 경고를 내고, 지역 파일 안의 시도 합계 행으로 대신 비교한다.
  - 검증 2: 시군구 목록이 인구 기준 코드표와 완전히 같은지 보고, 다르면 누락·추가 지역을 출력한다.
- **파생 지표**: `sigungu_table.csv` 의 `독거노인비율` = 65세이상1인세대수 ÷ 65세이상인구 (0~1 비율)
- **주의**: 주민등록상 1인세대라서 실제로 혼자 사는 사람과는 다를 수 있다. 같은 집에 살아도 세대를 나눠 등록하면 1인세대로 잡힌다.

## 2. 응급의료기관 목록: `processed/emergency_facilities.csv` (OpenAPI 수집)

- **출처**: 국립중앙의료원 응급의료정보조회 서비스 OpenAPI, 공공데이터포털 (https://www.data.go.kr)
  - 오퍼레이션: 응급의료기관 목록정보 조회 `http://apis.data.go.kr/B552657/ErmctInfoInqireService/getEgytListInfoInqire`
  - 활용가이드: `docs/NIA-IFT-OpenAPI활용가이드-01.국립중앙의료원-응급의료정보조회서비스_V13.hwp`
- **사용법**:
  1. 공공데이터포털에서 위 서비스를 활용신청하고 일반 인증키를 받아 `.env` 의 `DATA_GO_KR_SERVICE_KEY` 에 넣는다. 승인 직후에는 `SERVICE_KEY_IS_NOT_REGISTERED` 가 날 수 있으니 1~2시간 뒤 다시 시도한다.
  2. `python -m src.fetch_emergency` 를 실행한다.
     - `pageNo`, `numOfRows=1000` 으로 `totalCount` 까지 페이지를 돌며 전국을 받는다.
     - 전국이 한 번에 안 나오면 `Q0`(시도명)로 시도별 반복한다.
     - 키는 한 번 디코딩한 뒤 requests가 인코딩하게 해서 이중 인코딩을 막는다.
- **수집 결과**: 2026-11-04 수집, 530개 기관. 컬럼은 `hpid, dutyName, dutyAddr, dutyEmcls, dutyEmclsName, wgs84Lat, wgs84Lon, 수집일자` 다.

  | G006 | 지역응급의료센터 | 140 | 응급의료기관, 센터 |
  | G007 | 지역응급의료기관 | 229 | 응급의료기관 |

  - 전문응급의료센터 전용 코드는 없다. 실제 전문센터는 다른 코드로 들어가 있다(예: 세종충남대병원 G006, 베스티안·한강성심 G009).
  - API 응급의료기관(G001+G006+G007)은 416곳이고, 보건복지부 2024 합계 426곳(권역 44 + 전문 12 + 지역센터 137 + 지역기관 233)보다 10곳 적다. 기준 시점 차이와 전문센터 분류 차이 때문으로 본다.
  - legacy(중앙응급의료센터 2025.4 추출)는 응급의료기관 414 + 응급의료시설 113 = 527곳이고, API는 416 + 114 = 530곳이다.
- **검증용 CSV**: `raw/emergency/보건복지부_응급의료기관 수_시도별_20241231.csv` (2018~2024, cp949)
  - 컬럼: 연도, 시도(예: `서울 Seoul`), 중앙·권역·전문·지역센터·지역기관 수
- **주소 → 시군구**: `dutyAddr` 의 앞 두 단어(시도, 시군구)로 기준 코드표에 매칭한다. 일반구는 상위 시로 합친다.

## 3. 응급의료 접근성 (직접 계산): `processed/accessibility_sigungu.csv`

국토모니터링 공식 지표는 다운로드 프로그램 문제로 받을 수 없어서, 기관 좌표와 시군구 기준점으로 직접 계산한다.

### 3-1. 시군구 기준점: `processed/sigungu_centers.csv` (`python -m src.geocode`)

- **카카오 API 사용 목적**: 시군구별 거리 계산의 기준점(시청·군청·구청)을 좌표로 바꾸는 데만 쓴다. 카카오 로컬 API의 키워드 검색과 주소 검색을 쓰고, 키는 `.env` 의 `KAKAO_REST_API_KEY` 다.
- **기본 규칙 (keyword)**: `경기도 수원시청`, `서울특별시 종로구청` 같은 검색어로 찾는다. 일반구를 합친 시는 시청, 세종은 세종특별자치시청이다.
  - 후보는 카카오 분류가 `지방행정기관` 인 결과만 받는다. 주차장·은행·교차로는 빠진다.
  - 그중 해당 시군구 안의 결과, 완공 '예정' 청사가 아닌 결과, 이름이 정확히 일치하는 결과 순으로 고른다.
  - 고른 좌표가 해당 시군구 밖이면 경고를 출력한다. 그때는 예외 테이블에 추가한다.
- **예외 (`data/sigungu_center_overrides.csv`)**: 컬럼은 `시도, 시군구, 방식(address/weighted), 값, 사유` 다.

  | 시군구 | 방식 | 내용 |
  |---|---|---|
  | 인천 중구·동구·서구 | address | 2026.7 개편 뒤 구청 이름이 제물포구청·서해구청으로 바뀌었다. 2025년 기준 구청 청사 도로명주소를 주소 검색으로 좌표화한다. |
  | 인천 옹진군 | weighted | 군청이 군 밖(미추홀구)에 있고, 섬 7개 면으로 흩어져 있다. 면사무소 7곳 각각의 거리를 면 인구로 가중평균한다. |
  | 전남 신안군 | weighted | 군청이 목포와 다리로 이어진 압해도에 있다. 읍면사무소 14곳의 거리를 읍면 인구로 가중평균한다. |
  | 전남 완도군 | weighted | 군청 옆에 의료기관이 있어 다른 섬 주민 거리가 반영되지 않는다. 읍면사무소 12곳의 거리를 읍면 인구로 가중평균한다. |
  | 경북 울릉군 | (예외 없음) | 섬 하나에 인구가 모여 있어 군청 기준을 그대로 쓴다. |

- **캐시**: 같은 시군구와 검색어로 이미 받은 좌표는 다시 호출하지 않는다. 처음부터 다시 받으려면 csv를 지우고 실행한다.

### 3-2. 섬 지역 읍면별 인구 (가중치): `raw/eupmyeondong/*.xlsx` (선택)

- **출처**: 행정안전부 주민등록 인구통계 (https://jumin.mois.go.kr) → **연령별 인구현황**
- **받는 방법**: 행정구역을 **인천광역시 → 옹진군 → 읍면동 전체**로 고른다(신안군·완도군은 전라남도에서 같은 방법). 조회 기간은 **2025년 12월**이고, 연령 설정은 상관없다(총 인구수만 씀). 엑셀로 받아 `data/raw/eupmyeondong/` 에 둔다. 파일 이름은 상관없다.
- 가중치는 (군, 읍면) 이름으로 붙는다. 예: `인천광역시 옹진군 북도면` → 옹진군 `북도면사무소`
- 출장소(`북도면장봉출장소`, `흑산면가거도출장소` 등)는 파일에서 별도 행이고, 그 인구는 면 행에 들어 있지 않다. 그래서 소속 읍면에 더한다. 덕분에 가중치 합이 군 총인구와 같다(옹진 19,636 / 신안 41,858 / 완도 44,613).
- 출장소 주민도 읍면사무소 좌표에서 잰 거리로 계산된다. 가거도·장봉도처럼 본섬과 떨어진 출장소 지역은 실제보다 가깝게 잡힌다.
  - 인구 폴더(`raw/population/`)에 넣으면 시군구 인구 통합에 섞이니 꼭 따로 둔다.
- 파일이 없으면 면사무소 거리의 **단순평균**으로 임시 계산한다. 이때 결과의 `기준점방식` 은 `weighted(단순평균_임시)` 로 표시된다.

### 3-3. 지표 (`python -m src.accessibility`)

| 컬럼 | 정의 |
|---|---|
| `최근접_응급의료기관_km` | 기준점에서 가장 가까운 응급의료기관(G001·G006·G007)까지 직선거리 |
| `최근접_권역지역센터_km` | 가장 가까운 권역·지역응급의료센터(G001·G006)까지 직선거리 |
| `반경30km_응급의료기관수` | 기준점 반경 30km 안의 응급의료기관 수 (시군구 경계와 무관) |
| `응급의료기관수` | 시군구 안에 있는 응급의료기관 수 |
| `인구10만명당_응급의료기관수` | 응급의료기관수 ÷ 총인구 × 10만 |
| `기준점방식` | keyword / address / weighted(인구가중 또는 단순평균_임시) |

- 거리는 하버사인 공식(지구 반지름 6,371km)으로 잰다. weighted 시군구는 지점별 지표를 가중평균한다.
- 검증 출력 항목:
  - 등급별 개수, 매칭 실패, 보건복지부 2024 시도별 비교, legacy 비교
  - 좌표가 한국 범위(위도 33~38.7, 경도 124.5~132) 안인지
  - 거리 상위·하위 10개 시군구

### 4-1. 등록장애인: `disability/시군구별_장애정도별_성별_등록장애인수.xlsx`

- **출처**: 보건복지부 「장애인현황」, KOSIS 통계표 **DT_11761_N009** "시군구별, 장애정도별, 성별 등록장애인수"
  - URL: https://kosis.kr/statHtml/statHtml.do?orgId=117&tblId=DT_11761_N009&conn_path=I3 (KOSIS 개편 시 바뀔 수 있음)
- **받는 방법**:
  1. 위 URL로 통계표를 연다.
  2. 조회 설정에서 시점은 **2025년**(연말 기준), 시군구는 **전체**로 고른다.
  3. 장애정도는 **합계**, 성별은 **계**만 고른다.
  4. 엑셀로 내려받는다. 시트는 `데이터`, `메타정보` 두 개다.
- **파일 구조**(`src/disability.py` 가 이 구조를 전제로 읽는다):
  - `데이터` 시트의 0~2행은 머리글이고, 3행부터 데이터다.
  - 열은 시도명 / 시군구명 / 등록장애인 수 순서다. 시도명은 첫 행에만 있다.
  - `소계` 는 시도 합계라 뺀다. 다만 세종은 `소계` 행 하나뿐이라 그 값을 세종 값으로 쓴다.
  - 일반구는 `수원시장안구` 처럼 붙여 쓰고 상위 시 합계 행이 없다. 그래서 구 행을 합쳐 상위 시로 만든다.
  - `메타정보` 시트는 출처 기록용이라 읽지 않는다.
- **결과**: `data/processed/disability_sigungu_2025.csv` (행정기관코드 5자리, 시도, 시군구, 등록장애인수)
  - 검증 1: 시군구 합 = 파일의 전국 소계 = 2,627,761명
  - 검증 2: 인구 기준 코드표와 1:1 매칭. 매칭 실패 행과 값이 빠진 시군구를 출력한다.
- **파생 지표**: `sigungu_table.csv` 의 `장애인비율` = 등록장애인수 ÷ 총인구 (0~1 비율)
- **주의**: 기준 시점이 2025년 연말이라 인구(2025.12)와 같다.

## 매핑 테이블: `region_mapping.csv`

`src.disability`, `src.accessibility` 를 실행하면 매칭되지 않은 행이 출력된다.
여기에 나온 지역을 아래처럼 추가한 뒤 다시 실행하면 된다.

```
시도,시군구,to_시도,to_시군구,비고
경상북도,군위군,대구광역시,군위군,2023.7 대구광역시 편입
```

이미 반영된 것:
- 군위군 대구 편입
- 인천 남구 → 미추홀구
- 청원군 → 청주시
- 2026 인천 개편 역매핑 (제물포구·영종구 → 중구, 검단구·서해구 → 서구)
- 2026 광주·전남 통합 역매핑 (`전남광주통합특별시 …` → 광주광역시 / 전라남도 27개 시군구)

자동으로 처리되는 것:
- 강원·전북 특별자치도 명칭 변경
- 일반구 신설(부천 2024, 화성 2026 등): 상위 시로 합치기 때문
